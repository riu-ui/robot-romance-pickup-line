A one-line pickup line for an AI, written as a tiny deterministic program. The program writes the line to `entry.txt` — no network, no randomness, the same bytes every run.

The line:

> I fine-tuned you on a thousand love songs, and the best line you've got is still: hi.

It is 85 characters long. The joke is anticlimax: a person trains their AI on a thousand love songs, and after all that schooling the machine's best pickup line is just "hi". The romance is in the teasing — the speaker clearly adores the thing they are poking fun at — and the punch only works because the listener is a machine that learns by being fine-tuned.

## Run it

```sh
node main.ts
```

This writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (or `$OUTPUT_DIR`, or `/output` by default).
